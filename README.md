A project meant to create recipes, simulate the Plassys multi-angle evaporation chamber, and design Manhattan-Style Josephson Junctions for superconducting qubits. This GUI is meant to provide an enhanced understanding of chamber angles to ensure that your recipe is correct before you commit to it. Angles are adjustable in real-time and there is a Manhattan junction creator tab that simulates your design. The code then tries to predict shadowing limitations and create a reasonable recipe that can be turned into a text file. To run the GUI simulation, download or copy all 6 Python files and run plassys_master_gui.py.
